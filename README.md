# App análisis de emociones **AutiFeel**

## Introducción

**AudiFeel** es una aplicación móvil desarrollada en **React Native**, creada con el propósito de brindar apoyo tecnológico y accesible a personas dentro del espectro autista, así como a sus familias, acompañantes y profesionales de la educación y la salud.  
El proyecto busca ofrecer herramientas innovadoras que faciliten la comprensión emocional, mejoren la comunicación y proporcionen información confiable sobre el autismo desde un enfoque moderno, práctico e inclusivo.

La aplicación integra dos pilares fundamentales:

### 📸 Análisis de emociones mediante fotografía  
AudiFeel incorpora un sistema de reconocimiento facial capaz de analizar una imagen y detectar la emoción predominante del usuario.  
Esta funcionalidad fue diseñada para apoyar a personas autistas que pueden presentar dificultades para identificar, interpretar o expresar emociones, ofreciendo una herramienta visual y accesible que facilita la comunicación emocional en distintos contextos.  
El análisis es rápido, intuitivo y se presenta de manera clara para favorecer el entendimiento tanto del usuario directo como de quienes lo acompañan.

### 🤖 ChatBIA – Asistente virtual especializado en autismo  
El proyecto incluye **ChatBIA**, un asistente conversacional creado para resolver dudas, explicar conceptos y ofrecer información confiable relacionada con el autismo.  
Su objetivo es proporcionar orientación inmediata a usuarios, familiares, educadores y cuidadores, convirtiéndose en una herramienta de consulta constante y accesible.  
ChatBIA se enfoca únicamente en temas relacionados con el espectro autista, permitiendo obtener respuestas precisas, claras y adaptadas a las necesidades del usuario.
